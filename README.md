# Air Defender Radar (GCI / IADS) для Arma 3

Мод тактического радиолокатора ПВО и УВД (Управления Воздушным Движением) для Arma 3.
Выполнен в стиле монохромного зеленого дисплея ИКО (Индикатор Кругового Обзора / PPI) как в симуляторах ПВО («Air Defender»), с поддержкой **распределенной сети радаров (несколько РЛС на карте)**, нативного DataLink, отслеживанием ракет и сетевой C2-логикой перехвата.

---

## Ключевые возможности

1. **Распределенная сеть радаров (IADS Network / Несколько РЛС):**
   * Каждый радар на карте — это отдельный физический объект (радарный купол, вышка, мобильная станция ПВО, ЗРК).
   * Вокруг каждого радара очерчивается **свой собственный круг зоны покрытия** и дальности.
   * У каждого радара независимо вращается **свой собственный луч развертки**.
   * Радары покрывают **только свои сектора/области**. Между ними возникают «слепые зоны», где самолеты противника могут скрываться на малой высоте или за горами.
   * Если радар уничтожен (`!alive`), его круг на экране гаснет, луч останавливается, а зона покрытия исчезает.

2. **Аутентичный визуал зеленого экрана (Green CRT Vector Display):**
   * Темный фон без спутникового мусора.
   * Плавные лучи развертки с фосфорным шлейфом (persistence glow).
   * Линии упреждения курса (векторы скорости на 15–30 секунд вперед).

3. **Союзная авиация и IFF-ответчик:**
   * Отображение всех союзных самолетов и вертолетов (`playerSide`).
   * Формуляр цели: позывной, эшелон (высота ASL), путевая скорость (км/ч), курс, остаток топлива и процент повреждений.

4. **Интеграция с DataLink (Arma 3 Jets DLC):**
   * Использование нативного API сенсоров: `getRemoteTargets playerSide` + `getSensorTargets`.
   * На экран диспетчера выводятся все воздушные контакты, которые сопровождают радары союзных истребителей, самолетов ДРЛО (AWACS) и комплексов ЗРК (даже вне зоны действия наземных радаров!).

5. **Засечка ракет (ПРО):**
   * Отслеживание снарядов и ракет класса `MissileBase` и `RocketBase`.
   * При обнаружении подлетающей ракеты экран подает визуальную и звуковую тревогу, отображая скорость и траекторию.

6. **Командование и векторение (исправленная логика Drongo C2):**
   * **Для живых пилотов:** диспетчер выбирает союзный борт, затем цель и нажимает «Векторение на цель» — пилоту отправляется радиограмма и тактическая плашка с курсом, дальностью, высотой и расчетным временем схождения (ETA).
   * **Для ИИ-бортов:** команды `Перехват (Scramble)`, `Патруль (CAP)` и `Возврат на базу (RTB)`.
   * **Сетевая оптимизация:** команды ИИ передаются через `remoteExecCall` строго на владельца группы (`groupOwner`), что гарантирует **100% стабильную работу на выделенном сервере (Dedicated)** без сбоев путевых точек.

## Как расставлять радары в редакторе (Eden Editor)

### Автоматическое обнаружение
Мод автоматически распознает стандартные радары Arma 3:
* `Land_Radar_F` (Большой купол РЛС) — радиус покрытия **35 км**.
* `Radar_System_01_base_F` / `Radar_System_02_base_F` (РЛС ЗРК из Jets DLC) — радиус **35 км**.
* `Land_Radar_small_F` / `Land_Airfield_Tower_F` (Малая РЛС / Вышка УВД) — радиус **15 км**.
* Техника с включенным бортовым радаром (ЗРК, ЗСУ, радары ПВО) — радиус **20 км**.

### Ручная настройка любого объекта как РЛС
Вы можете превратить **любой объект** (бункер, вышку связи, командно-штабную машину, палатку) в радарную станцию. Для этого пропишите в поле `init` объекта в редакторе:
```sqf
this setVariable ["AIRDEF_isRadar", true, true];
this setVariable ["AIRDEF_radarRange", 25000, true]; // Радиус покрытия в метрах (например, 25 км)
this setVariable ["AIRDEF_radarName", "РЛС Северный Рубеж", true]; // Название на карте
```

## Установка и запуск

1. В папке проекта уже собран готовый файл: `Addons\arma_radar.pbo`.
2. Создайте папку `@AirDefender_Radar` со структурой:
   ```
   @AirDefender_Radar\
   ├── mod.cpp
   └── Addons\
       └── arma_radar.pbo
   ```
3. Подключите `@AirDefender_Radar` как локальный мод в лаунчере Arma 3.
4. В игре:
   * Нажмите `Ctrl + R` (при установленном CBA_A3).
   * Или через меню действий персонажа: **`[РАДАР ПВО / УВД] Открыть терминал`**.
   * Или добавьте на стол/ноутбук действие:
     ```sqf
     this addAction ["<t color='#00FF44'>Терминал РЛС ПВО</t>", { [] spawn AIRDEF_fnc_openRadar; }];
     ```
5. Пересборка мода после правок — запуск `build.bat` (или `py pack_pbo.py`).
